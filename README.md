# 💧 Water Network Optimizer

A Python engineering toolkit for hydraulic pipe sizing and head loss optimization in water distribution networks.

## Features
- Hazen-Williams head loss calculations
- Automated commercial pipe diameter selection
- Velocity constraint validation (0.6 - 2.5 m/s)
- CSV export for CAD / Hydraulic reports
- Unit tested with pytest

## Quick Start

`ash
python -m water_network_optimizer examples/sample_network.json
pytest

`
